# Charmel Paris — Luxury Salon Website

النسخة الأولى جاهزة للنشر وتحتوي على:
- موقع فاخر RTL أسود + ذهبي.
- شعار Charmel Paris الذي أرسله العميل داخل `assets/logo.jpg`.
- أقسام: الرئيسية، عن الصالون، الخدمات، المعرض، الحجز، التواصل.
- نموذج حجز يفتح WhatsApp.
- صفحة `admin.html` كبداية للوحة التحكم.
- جاهزة للمرحلة التالية للربط الحقيقي مع Supabase Auth + Database + Storage.

## النشر
ارفع الملفات كما هي إلى GitHub Pages أو Cloudflare Pages أو أي استضافة static.

## المرحلة التالية
لجعل لوحة التحكم حقيقية لجميع الزوار:
1. Supabase Auth للمدير.
2. جداول للخدمات والحجوزات والمحتوى.
3. Supabase Storage للصور.
4. RLS لحماية البيانات.
5. منع أي وصول إداري بدون حساب admin.
